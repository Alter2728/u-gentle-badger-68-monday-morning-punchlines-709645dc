One joke about Monday mornings, entered in the [make.fun](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty "Monday Morning Punchlines". A judge model reads the jokes two at a time and picks the funnier one — the funniest joke takes the $5 pool.

> "Monday morning, my motivation called in sick — so my snooze button applied for its job, and got it."

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Python 3 standard library only, deterministic — running it twice produces byte-identical output.
